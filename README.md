# ChainQuartz

ChainQuartz enables distributed, event-driven systems to process real-time data to function as a highly concurrent processor and orchestrator.

ChainQuartz is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/ChainQuartz.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure ChainQuartz, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
